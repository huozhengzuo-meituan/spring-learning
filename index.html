你最终要能独立完成什么

设计接口 → 守住数据 → 缓存与事件 → 观测与交付

不只写出 CRUD：解释一个请求如何被认证、如何提交事务、为什么消息会重复，以及系统出故障时先找什么证据。

项目随课程一起交付

hello-api / task-service 运行手册：前者聚焦 REST 与测试；后者默认用 H2 即可启动，进阶切换 PostgreSQL + Redis + Kafka。高级课程中的增量实验有明确任务与验收，并非所有生态组件都已集成到项目。
