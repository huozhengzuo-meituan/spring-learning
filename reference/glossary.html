前后端术语对照

类比帮你开始，边界帮你判断

术语含义不要误解为
IoC / DI容器组装对象 / 用构造参数等表达依赖每次请求创建所有对象
BeanSpring管理的对象，默认单例每个前端组件独立的状态
DTO / Entity接口契约 / 数据库映射两者总能直接共用
事务指定数据源内操作共同提交或回滚远程网络调用也一起回滚
乐观锁用版本条件检测过期更新冲突后总能自动重试
TTL限制缓存存活时间到期前数据一定最新
幂等相同操作重复执行不额外改变业务结果前端禁止重复点击
Partition / Offset有序日志单元 / 单元内位置全局序号和业务成功凭证
Outbox业务和待发事件同库同事务网络发布从此绝不重复
SLI / SLO用户体验指标 / 指标目标没有分母和窗口的口号

把保证的范围说完整

认证回答你是谁，授权回答你能对哪个资源做什么。角色检查不能代替资源归属检查。线程安全涉及进程内共享对象，分布式正确性还涉及不同进程、网络与持久化状态。

说“同一个数据库事务内原子”“单个 Kafka 分区内有序”“对这个 eventId 幂等”。没有范围的结论，补充成立条件后再找反例。
