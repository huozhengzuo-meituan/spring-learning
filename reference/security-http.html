接口与安全速查

协议是给调用方的承诺

状态语义动作
201资源创建成功用返回ID和Location
400格式或校验失败呈现字段问题
401认证缺少或无效按登录协议处理
403授权或安全校验失败查权限、归属、CSRF
404不存在或不应披露存在性呈现不可访问
409版本或状态冲突刷新并重新决策
429 / 503限流 / 暂时不可用按约定退避

ProblemDetail的type、title、status、detail、instance构成错误契约。不要返回SQL、堆栈、口令或token；内部诊断通过日志关联。

浏览器的安全边界

Basic账号只用于本地教学。浏览器自动带Cookie，也可能自动带已有Basic凭据，因此REST或无Session不足以成为关闭CSRF的理由。示例保留CSRF，写入前先获取token。

CORS限制浏览器读取跨源响应，不替代鉴权。带凭证的origin不能用通配符。XSS和CSRF互不替代；凭据存储要结合BFF、Cookie属性与脚本攻击风险考虑。

JWT不是登录协议

OAuth2处理委托授权，OIDC提供身份语义。资源服务器检查签名、可信issuer、audience、有效期、算法约束与权限映射；decode不是验证。密钥轮换与权限撤销需另有策略。

测试匿名、无权限、有角色却访问别人资源、合法访问四种路径。示例reader/writer是公共任务池角色教学；资源归属和OIDC接入属于课程增量，不要把演示账号部署公网。
