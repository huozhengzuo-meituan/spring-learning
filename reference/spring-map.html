课程基线

使用 Java 21 LTS、Spring Boot 4.1.1；不启用 preview。Java25 是 LTS 升级比较方向。Boot4.1.1最低Java17，课程主动选择21，以现代特性建立可迁移的后端能力。

识别老教程

  • 使用 jakarta.persistence、jakarta.validation；不要机械改掉JDK自带的所有javax包。
  • Security采用SecurityFilterChain Bean，而非旧WebSecurityConfigurerAdapter。
  • Boot4拆分技术模块和测试starter；依赖与导入以项目源码为准。
  • 默认Jackson3，databind属tools.jackson；注解仍可能来自com.fasterxml，不能全局替换。
  • Kafka4使用KRaft，无须先部署ZooKeeper。
  • Cloud先查release train兼容表，不独立拼各个最新版本。

升级顺序

保存依赖树与测试基线 → 阅读迁移指南 → 每次修改一层版本 → 修正编译配置 → 跑真实依赖集成测试 → 验证错误路径与回滚。固定版本方便复现实验，实际部署仍须跟踪补丁。可以下载不代表运行兼容。
