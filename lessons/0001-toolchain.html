把 Java 工具链跑通

用同一套工具完成编译、测试和启动，识别版本不匹配。

约 25 分钟先修：基本 Java 语法Java 21 · Boot 4.1
从你的前端经验出发

把 JDK 看成运行时加编译工具，把 Maven 看成依赖解析和构建生命周期；它与 Node/npm 相似，但编译目标和运行时需要分别检查。

本课服务于同一个目标：独立交付并排查可靠的业务后端。实验入口：examples/hello-api。标注为教学片段或设计实验的代码需要按题目补入，不代表示例已实现该功能。

建立可复现的版本基线

课程使用 Java 21 LTS 和 Spring Boot 4.1.1，目的是在有长期支持的语言基线上学习现代框架。Boot 4 的最低 Java 要求并不等于本课选择的版本：官方当前要求至少 Java 17，并支持 Java 21。Java 25 也是后续可评估的 LTS；学习阶段先固定一个版本，避免把安装、语法和框架升级问题混在一起。LTS 描述支持策略，补丁支持期限仍取决于发行商。

JDK 包含 java、javac、jshell 等工具。IDE 的 Project SDK、终端的 java、Maven 实际使用的 Java 可能来自不同安装路径。出现 UnsupportedClassVersionError 时，先确认运行字节码的 JVM 版本；遇到 release version 21 not supported，则先确认编译器版本。不要通过删除业务代码去修复环境不一致。

从依赖到可运行服务

工作区的 examples 是 Maven 聚合项目，hello-api 用内存保存任务，先让你专注 HTTP 和 Spring。构建命令经历依赖下载、编译、测试、打包等步骤。首次下载慢与测试失败是两种不同证据。看到构建成功只说明当前检查通过；真正监听端口并响应请求，需要再启动服务和调用 API。

下列命令均从工作区根目录执行。启动命令会一直运行，请另开终端执行 curl。Ctrl+C 停止服务，不等于关闭整个工作区；内存数据会随服务停止丢失，这正是后面引入数据库的动机。

source scripts/env.sh
java -version
./mvnw -version
./mvnw -f examples/pom.xml verify
./mvnw -f examples/hello-api/pom.xml spring-boot:run
# 第二个终端：查看状态行、响应头和 JSON
curl -i http://localhost:8081/api/tasks

原始资料：Boot 4 官方迁移指南。

版本边界与排错顺序

看到 8081 端口占用时，先识别占用进程，或用命令行参数选择另一个端口，不能把任意 Java 进程全部杀掉。依赖解析失败时检查 Maven 错误中的仓库地址、坐标和网络；不要直接替换成来源不明的仓库。Boot 4 使用 Jakarta 命名空间，并优先使用 Jackson 3；旧教程里的 javax.validation 和 Jackson 2 自定义序列化代码不能照搬。

为自己保存三条证据：JDK 版本、完整构建命令与结果、一次 API 的状态码。以后求助时提供这三条比“启动不了”更可诊断。完成本课的标准是能从干净终端重复以上过程，并说明哪一步是构建，哪一步是进程运行，哪一步是网络访问。

当前工作区可从根目录执行source scripts/env.sh选择局部JDK。全新clone若使用系统安装的Java21，请按SETUP.md配置JAVA_HOME，无需执行局部工具链脚本。新的终端需要重新加载对应环境。请保留系统原有工具，不用为了学习直接升级所有项目的全局Java。终端能跑通之后再对齐IDE，可以减少同时排查两套环境的负担。

原始资料：Boot 4 官方迁移指南。

合上笔记，先判断

IDE 能运行而终端编译失败，优先检查什么？
查看判断依据

正确答案：双方工具版本。IDE 与 Maven 可能使用不同 JDK。先对齐环境，再看编译错误，而不是猜测业务逻辑。

把知识变成操作

运行基线，并记录你自己的环境证据。

  1. 执行 java -version 与 ./mvnw -version，比较主版本。
  2. 执行聚合 verify，保留失败阶段或 BUILD SUCCESS。
  3. 启动 hello-api，curl /api/tasks，随后 Ctrl+C。
验收信号

两个版本命令使用 Java 21；构建成功；GET 返回 HTTP 200 和任务列表。

做完再看：参考答案与排错线索

若 Maven 显示其他 Java，调整 JAVA_HOME 或 IDE Maven Runner 的 JDK 后重试。若端口冲突，运行 ./mvnw -f examples/hello-api/pom.xml spring-boot:run -Dspring-boot.run.arguments=--server.port=8181，然后 curl http://localhost:8181/api/tasks。
